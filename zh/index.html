阅读操作说明
  1. 打开文件夹或存储卡。图库一次显示一张照片
  2. 按 g 切换到网格并比较项目
  3. 按 s 以 100% 比例检查照片
  4. 标记保留请按 f ，标记舍弃请按 d。星级和颜色标签单独设置
  5. 筛选已标记保留的项目
  6. 打开 Export 预览复制结果：7 个项目，14 个 RAW+JPEG 文件。原始文件保留在源位置

照片、视频、音频和文本

在图库查看照片、播放视频和音频，并用键盘控制播放

支持常见相机 RAW、JPEG、TIFF、PNG、HEIC、WebP 和 AVIF。可将匹配的 RAW+JPEG 合并显示为一个项目，并分别设置保留决定、星级和颜色标签

可在媒体旁阅读文本、Markdown 和结构化文件。文本预览只读，支持选择文本及打开网页和电子邮件链接

放大与比较

以 100% 比例检查照片，查看直方图和高光或暗部溢出，或使用手机尺寸预览。可选提示标出高 ISO、慢快门和过暗或过亮区域

在 Mac 本机查找完全重复文件、可能相似的照片和连拍组。分析不会自动修改评分或文件

筛选、排序与整理

按保留决定、星级、标签、日期、文件夹、相机信息和文件类型筛选。决定自动保存，下次继续使用

Organize Source Folder 在移动文件前预览文件夹结构。Rename Files 预览新名称，并将识别出的 RAW+JPEG/XMP 文件组一同处理。两者均可在当前会话中撤销

导出与清理

默认导出副本。也可选择同一磁盘内的 Move、将副本分送到多个文件夹，或写入兼容编辑软件的 XMP 附属文件

标记舍弃不会将文件移入废纸篓。Clean Up 是独立操作，将不需要的文件移入 macOS 废纸篓。当前会话中，只要文件仍在废纸篓，就可撤销

本机运行、免费与开源

Louppe 在本机处理媒体，无需账号，也不收集应用使用分析。直接下载版无需 Homebrew。应用免费，并以 MIT 许可证开源

编辑前筛选照片

使用 Louppe 进行照片排序与筛选：比较 RAW+JPEG 照片，为选择评分，并导出精选照片进行编辑

管理混合媒体文件夹

按日期、评分和文件信息排序照片、视频和音频。应用更改前预览文件夹整理结果和文件名

在 Mac 本机筛选

Louppe 是适用于 Apple 芯片 Mac 的本机筛选与文件管理应用。它不编辑照片；请将选择导出至兼容编辑软件
